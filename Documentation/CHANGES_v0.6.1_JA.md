# v0.6.1 — スポーン安全ガラス・明るさ・グロー・街並み

## スポーン背後の落下対策

カフェ南壁の中央5 mの開口を塞ぎました。ガラスは6面、真鍮の縦枠・目線下の細い表示線・足元灯付きです。スポーンと各ワープの着地点は維持しています。

- Unity座標の衝突中心 `(14, 4.8, 0.125)`、寸法 `(5.12, 9.8, 0.24)` m。
- `ARCH_EntrySafety/COL_EntrySafetyGlass` に床から屋根まで連続したBoxCollider。両側の壁・床・屋根に重ね、パネルの継目にも穴を作りません。
- PC／Questとも `MAT_SafetyGlass` を保持。東側の装飾窓を省略するQuest処理とは分離しています。
- 透明面は影を落とさず、OccluderStaticとContributeGIの対象から外します。見える街並みを不透明な壁として遮蔽しないためです。

## 明るさ

カフェのBlenderレンダーは従来の露出1.05を維持し、光源・素材・Unity環境色を変更しています（カート用レンダーも従来の1.5を維持）。

- カフェの既存灯出力1.65倍、FPV／カートの既存灯1.35倍。Unity生成用マニフェストも同じ倍率で更新。
- 入口・中央ラウンジ・上階南通路にベイク用の補助灯3灯。東・北側にコーブ照明。
- 左官・床石・木・鋼材の基準色を明るく調整。
- 夜間の環境光・素材補助光を増加。昼間も補助色を調整し、全時間帯の見やすさを改善。
- カートは屋内の青紫色を維持し、路面の補助光と固定Tintを明るく調整。
- Unityのベイク光強度上限は6→10。街並みに追加するリアルタイム灯は0。

## 環境グロー

| 設定 | v0.6.0 | v0.6.1 |
| --- | ---: | ---: |
| PC Bloom intensity | 0.16 | 0.60 |
| Bloom threshold | 1.15 | 1.05 |
| Bloom soft knee / diffusion | 0.55 / 4 | 0.60 / 5 |
| PC 器具グロー 暖色／寒色 | 0.035 / 0.030 | 0.090 / 0.075 |
| Quest 器具グロー 暖色／寒色 | 0.028 / 0.023 | 0.060 / 0.050 |

グローカードの範囲を拡大し、入口とテラスにも追加しました。PC Bloomは従来どおりPost Processing Stack v2導入時のみ。Questは器具グローと発光材を利用します。SOFT GLOW／LOW EMISSIONによるローカル調整も利用できます。

## 周囲の建物

単純な黒い30棟を、意匠を揃えた24棟へ更新。東側だけでなく南側の新しいスポーンガラスからも街並みが見えます。

- 各棟3段のセットバック、石の柱・水平帯、金属感のある不透明ガラス外装。
- 暖色／寒色の窓、発光する冠部、屋上庭園、2本の空中回廊。
- 高さ22〜62 m（基部Z=-8 mから）、棟ごとの高さと間隔を固定。再生成で配置が変わりません。
- `ENV_City` 内で材質ごとにバッチ化。新しいテクスチャ画像・物理・リアルタイム光源は追加していません。
- Questでも窓と冠部の発光を保持。街並み実測はPC 30,236 tris／Quest 18,804 tris、各6メッシュ。PC 36,000／Quest 28,000 trisの上限内です。
- 街並みは背景用。屋上・空中回廊へ移動するための床やワープは設けていません。
