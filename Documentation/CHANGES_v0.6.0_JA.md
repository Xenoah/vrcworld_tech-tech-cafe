# v0.6.0 — APEX / NEON SWITCHYARD

写真のような、タイトでテクニカルなネオンの屋内カート空間へ全面改修しました。参考写真から取り入れたのは囲われた空間の密度と青・紫の光です。走路は独自の34頂点から円弧と連続勾配を生成したオリジナルレイアウトで、実在施設のコースを再現していません。

| 項目 | v0.6.0 |

低層REACTOR、中層CROSSFIRE、上層SKYLINEを連続走路で巡ります。連続する切り返しと橋下を組み合わせ、外周の加速区間から内側のタイトな区間へ入る構成です。独立した屋内フロアと3層構成、カフェとの往復ワープを維持します。

## 光と造形

- 全面屋根・外壁・鉄骨トラスを追加。黒い光沢路面、0.75 m高のラバーガード、ピンク／白のパネルと縁石。
- 青／シアン／紫の上端LEDに加え、低い走行目線で見える側面LEDと路面ガイドを配置。壁面に紫の縦照明、天井に青紫の照明。
- チェッカー、琥珀色の進行矢印、区画名を配置。点滅演出は追加していません。
- 6台分の空の配置ガイド、ピット、3段の観戦席、屋根、ピット両端の歩行動線、時間操作パネル。
- 室内マテリアルは外の時刻に依存しない発光と色を使用。カート滞在中の環境色・霧を青紫で固定し、カフェ／FPVの時間切替を維持。
- PCにカート用ベイク反射プローブを追加。広い外壁・屋根のライトマップ密度を抑制。

ネオンの側面帯は見える面だけを生成し、同じ材質の装飾をバッチ化しています。PC／Questとも路面とガードの当たり判定は共通。カート名のオブジェクトがカートのコレクションに属することも検査し、エリア描画切替から装飾が漏れないようにしました。

## 画像と再生成

実モデル画像5枚を1600 × 1000で収録し、Release Assetsへ添付します。すべてBlender 4.5.3 / Cycles。全景だけはレイアウトが見えるよう屋根・手前2面の壁・トラスを非表示にしたカットアウェイです。橋下・走行・ピット・上層の4枚は閉じた屋内モデルのままです。Unity／VRChatの撮影と区別しています。

設計正本は `SourceDesign/kart_circuit.json`、平面図は `CAD/APEX_Kart_Neon_Switchyard_v06.dxf`。再生成手順はREADME_JA.md。`Blender/render_kart_views.py` で最終画像5枚、`--draft` で作業用の低解像度画像を生成します。配布時は `package_release.py` と `verify_release.py` を実行し、画像もSHA-256で照合します。
