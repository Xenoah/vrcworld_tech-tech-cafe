# v0.5.0 — APEX / TRI-LAYER KART

カフェ・VECTOR FPVに続く、独立したレーシングカートフロアを追加しました。車両には所有者が導入するCVS2を利用します。

| 項目 | 実装値 |
| --- | --- |
| フロア | 320 × 300 m、カフェから離れた位置 |
| 周回長 | 1,398.68 m |
| 走行幅 | 8 m、縁石とガードを含むデッキ幅9.9 m |
| 3レイヤー | 0.35／3.95／7.55 m |
| 立体構成 | 3か所の交差、連続スロープ、5か所のS字 |
| 最大勾配 | 8.95% |
| 最小中心旋回半径 | 14.73 m（走行帯内側10.73 m） |
| 橋下面の最小空間 | 6.75 m |
| 区間表示 | 低層シアン／中層アンバー／上層ライム、矢印、縁石、スタートライン |
| ピット | 空の配置ガイド6か所、路面と接続したエプロン、観戦側への歩道 |
| 観戦 | 3段のスタンド、屋根、独立したワープ着地点 |

PC／Questとも同じ連続路面・ガード形状を使います。路面とガードの静的MeshCollider、支柱などのBoxColliderをUnity生成処理へ追加しました。旋回半径・勾配は初期設計値であり、CVS2車両の速度・車高に合わせた実走調整は別途必要です。

## 接続と描画

- カフェ入口APEX / KARTと観戦側RETURN / CAFEで往復。
- 観戦側にも朝昼夕夜・±1時間・CYCLE / HOLDの操作パネルを追加。
- カフェ／FPV／カートの3エリアで建築描画・音声ゾーンを切替。当たり判定とUdonは維持。
- シーン生成後に導入する外部CVS2車両は、建築Rendererの表示切替対象にしません。
- 広域用に霧を弱め、PC／QuestのReference Cameraをfar clip 900 mで設定。PC Bloomの導入有無によらず参照カメラを設定。

## CVS2

`KART_ExternalVehicleAnchors/CVS2_Bay_01`〜`06` は位置・向きのガイドだけです。CVS2本体、カートモデル、操縦、車両同期、ラップ計測、レース管理は含みません。[導入メモ](CVS2_INTEGRATION_JA.md)を参照してください。

従来形状35項目＋カート15項目を検査。連続デッキ、面の向き、幅、勾配、旋回半径、3層、実三角形同士の橋下空間、支柱と走行路・ピットの干渉、ピット面の折り返し、6ガイドの床支持、ワープ着地を確認。C#構文12ファイル、Blender相対参照、Unityメタデータ、配布物の全バイト一致も検査します。

**Unity/Udon・シェーダーのコンパイル、ベイク、CVS2走行・同期、VRChat内の表示、PC／Questの実測性能は未検証です。** 大面積のライトマップと同時走行時の負荷はUnity側で確認してください。
