# CAD正本に対する変更提案と今回の実装

元のCAD・world_spec.jsonを変更せず保存しています。以下は歩行可能な制作データを成立させるための**明示的な補完案**です。`The_Commons_Implementation_Overlay_v02.dxf` は実装平面であり、元正本の改訂を装ったものではありません。

| ID | 元資料の不整合・不足 | 今回の実装 |
|---|---|---|
| C01 | 2F基準はJSONで4.800m。断面の床上面は4.850m、SCADの床上面は4.900m | 仕上床上面をJSONの4.800mに統一。床厚0.200m、下面4.600m |
| C02 | 主画面はJSONが7.1×4.0m、断面図の枠は7.6×3.8m | 有効画面を7.1×4.0m、中心(14,16.83,2.4)mに採用。16:9の近似値 |
| C03 | ポスター仕様は6面以上、平面CADにある描画は5面 | 東壁の5面を維持し、南側の返しに6面目を追加。4台の小型デモ台も配置 |
| C04 | 北橋がX=19.5で止まり、東床がX=20から始まる | X=19.5〜21.3、Y=15.0〜17.55に接続床を追加 |
| C05 | Quiet北端Y=7.8とTerrace南端Y=9.0の間に床が未指定 | X=21.3〜27.5、Y=7.8〜9.0を接続。階段側の吹抜けを残す |
| C06 | 西カフェY=4.2開始と南橋Y=2.6〜5.0の接触幅が0.8m | X=7〜8.8、Y=2.6〜4.2に接続床を追加 |
| C07 | 元床には階段開口がなく、西上端の踊り場も狭い | 西開口X=7〜8.8/Y=11.8〜16.1、東開口X=20〜21.3/Y=7〜13.5。西の北端床をY=17.55まで補い、上端の床奥行きを1.45m確保 |
| C08 | 西階段の指定枠2.0×4.8mでは4.8mの上昇を緩勾配にできない | 幅1.5m・25段・勾配48.14°の外観、単純斜面コライダーと隣接ポータル。平面外へ無断で長い階段を伸ばさない |
| C09 | DJ床により上階の一部から主画面の上方が隠れる | 北面上階に5.68×3.2mの補助画面。同じ映像ソースを使い、別動画プレイヤーを増やさない |
| C10 | Quiet Roomの壁高・天井・開口の細部未定義 | 2Fに高さ3.5mの間仕切り、上面8.46mの天井、南橋から入る開口を設ける |
| C11 | 階段口、上階外周の手すり・落下防止形状が未記載 | 上階の開放床端に高さ1.05mの手すり。単純な高さ1.3mの衝突範囲を分離 |
| C12 | 250mmステージへの移動方法が未指定 | 南側に幅1.5mの目立たないアクセス斜面を追加 |

基本外形28×18m、1F/2F高さ、中央の吹抜け、ステージ中心(14,13.2)mと直径4.8m、1F西バー、2Fのカフェ/DJ/Quiet配置は維持しています。

屋根の+9.600mは屋根下面の基準として採用し、200mmの屋根板上面は+9.800mです。外景は建物外の演出メッシュであり、建物の504m²の床面積には含みません。

上階接続の検査は床と簡易コライダーの平面上で行ったもので、アバター差やQuestの実移動を代替しません。家具は接触を過度に妨げない方針とし、一部の小物・椅子本体には衝突を付けていません。
