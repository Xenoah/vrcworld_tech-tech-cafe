# CVS2導入メモ

本パッケージはコース・当たり判定・ピットの配置ガイドを用意します。CVS2と車両は含まれません。

1. 所有者が正規に取得した [CHIKUWA VEHICLE SYSTEM 2](https://booth.pm/ja/items/3129945) を、その版の説明書に従ってVCCプロジェクトへ導入してください。必要なSDKとパッケージはCVS2側の指定を優先します。
2. The CommonsのPC／Questシーンを生成します。再生成は新しいシーンを作るため、車両配置は生成後に行います。
3. `KART_ExternalVehicleAnchors/CVS2_Bay_01`〜`06` の空Transformを位置・向きの目安にします。v0.7.0ではメインストレート南側へ移動し、Unity座標はY=0.47、Z=25.60、X=231.197〜270.775です。車両Prefabの構成やホイール位置を保ち、使用車両に合わせて床との高さを調整してください。
4. 路面・ガードは静的MeshCollider、支柱などはBoxCollider。車両のタイヤ判定、衝突レイヤー、速度、復帰設定は車両の説明書に従います。ワールド生成処理がCVS2の内部設定・スクリプトを変更することはありません。
5. 低速で全周走行し、段差・橋下・ガード・ピットを確認してから速度を調整します。v0.7.0の走行幅5.2 m、中心半径6.0〜18 m、最大勾配10.60%、カルーセルのバンク最大8°、立体交差の最小クリアランス3.37 mは幾何検査値で、特定車両の走行保証ではありません。33コーナーには半径6 mのヘアピン、バンク付きの登りカルーセル、曲がりながらの登坂、2層分の下りが含まれるため、低速で最小旋回・車体幅・壁接触・坂道とバンクでの接地を確認してください。
6. PC／Quest・複数人・所有権移動・途中参加・乗降・リセットをBuild & Testで確認。[ACCEPTANCE_JA.md](ACCEPTANCE_JA.md)も参照してください。

外部車両を `CommonsAreaVisibility` の建築Renderer配列へ登録しないでください。建築が非表示でも車両の物理・Udon・同期を維持します。

車両システム、ラップ計測、スタート進行、スコア、車両リセットボタンは追加していません。必要な機能は導入したCVS2側で設定してください。
