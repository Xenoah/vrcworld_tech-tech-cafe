# v0.7.0 — APEX / NEON SWITCHYARD テクニカルコース改修

カートコースの走路だけを作り直しました。90°・半径6 mの切り返しを並べた従来の線形を、世界の実在サーキットにある代表的なコーナーの性格を取り入れた **33コーナー・3層** のテクニカルコースへ変更しています。

**カフェ・FPV・街並み、カートの建屋（床・外壁・屋根・トラス・壁面灯・天井灯）は変更していません。** 後述のとおり、Unity生成用データの該当部分がv0.6.1とバイト単位で一致することを確認しています。

## 走路まわりの変更

- 各コーナーの5 m手前の路面に、金色の「T1」〜「T33」を描きました。勾配・バンクに合わせて傾けています。
- 進行矢印をスロープ・バンクの面に沿わせました。従来は水平に置いていたため、スロープ上で一部が路面に埋まっていました。
- タイヤを下層コーナー内側の8か所で床へ直接置く配置に変更（2段積み、計48個）。従来は路面高で配置していたため床から浮いていました。上層・中層ではガードのみです。
- ピット・観戦デッキ・屋根・6台分のCVS2配置ガイド・帰還ポータル・時間パネルは、新しいメインストレート（Y=34 m）の南側へ移しました。構成と寸法は従来と同じです。
- 区画名の看板を新しい層配置に合わせて移動。奥の壁の表記は「33 TURNS / 3 LEVELS / FIND YOUR LINE」。
- 支柱は下の路面を避けて配置し、98本すべてが走行面と干渉しないことを検査しています。

## 変更していないものの確認

| 対象 | 確認内容 |
| --- | --- |
| Unity用メッシュ | `TheCommons_PC/Quest.tcmesh.bytes` のうちカート以外のPC 158件・Quest 150件のメッシュ記録がv0.6.1とバイト一致 |
| Unity生成用マニフェスト | カフェ・FPV・街並み・材質・座席・カート以外のコライダー163件・光源27件・カメラがv0.6.1と一致 |
| Blender原本 | カート以外の7,132オブジェクトの形状・配置・材質・光源出力がv0.6.1の再生成結果と一致 |

制作環境のBlenderがv0.6.1作成時の4.5.3から4.5.14 LTSへ上がり、同じソースでもUVの丸め（1e-6程度）とQuest用の間引き結果がわずかに変わります。カフェ・FPV・街並みを変えないため、Unity用メッシュのカート以外の記録はv0.6.1のものを使っています。参照用のFBX・glTFは全体を書き出し直しているため、カート以外にもこの丸め程度の差があります。Unityのシーン生成は `.tcmesh.bytes` を使います。
