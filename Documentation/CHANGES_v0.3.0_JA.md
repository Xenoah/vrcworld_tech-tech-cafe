# v0.3.0 — 小物の印刷と面の干渉修正

## 専用テクスチャ

新規の画像生成アトラス3枚を実際のメッシュへUVで割り当てた。原本PNGを保持し、Unity取り込み時にPC最大1024 / Android最大512へ制限する。

| アトラス | 内容 | 割り当て |
|---|---|---|
| relay_controller | 架空機材RELAY R2。波形表示、ジョグ、4ch目盛り、EQ、パッド、CUE/PLAY | 機材の天面と、絵柄に合わせた立体操作部 |
| bar_labels | ANCHOR / ORBIT / HORIZON / RELAY / ARCHIVE / COMMONS | バックバー93本。曲面ラベル、6種を1材質に集約 |
| cafe_props | エスプレッソ圧力計、AV機材、本6種の背表紙、コーヒー包装 | エスプレッソ機、ラック27段、本72冊、コーヒー袋3個 |

ラベルと操作面はタイル素材ではないためClampを使用。UVをセル内へ収め、ミップマップ用の余白を取った。元の建築素材6種はMirrorを継続。

## チラつきの原因と修正

v0.2.0の実形状を平面ポリゴンで調査した。

- ステージ下地の上面と木製円盤が同じ高さで約17.783 m²重複。下地の上面そのものを木材に変更して二重面を除去した。直径4.8 m、高さ0.25 mは維持。
- 北東接続床とテラス踊り場が約2.340 m²重複。踊り場を隣接床の端で止めた。
- 西階段上端の補助床が北橋に約0.290 m²埋め込まれていたため補助床を除去した。通行床とコライダーの連続性は検査した。
- 1階の44本の薄い床目地が459箇所で交差。立体の細線を除去し、床テクスチャで表面を表現する。
- 東西53段で踏み板と蹴込み板の上面・側面が競合。蹴込みを踏み板の下までにし、段鼻は手前の別位置へ配置。上端の踏み板延長も解消。
- 壁のコーナー、バーカウンター下地と天板、手すりの重複支柱・柱脚も整理。
- 印刷面は原則として既存ポリゴンの材質を差し替える。ボトルの曲面ラベルだけはガラスから3 mm離れた専用の帯状メッシュ。

歩行床・ステージ・階段の上向き面に対し、同一高さの実ポリゴン交差面積が `1e-5 m²` を超えないことを自動検査する。接するだけの境界は許容する。全オブジェクトの接触をなくす検査ではなく、クッション等の内部接合や遠景ビルの底面は対象外。

## 導入と再生成

既存の生成済みUnityシーンには自動で反映されない。更新した `TheCommons` フォルダーを導入して新しいシーンを生成する。[Unity MCP手順](../UNITY_MCP_HANDOFF.md) を参照。

再生成順: `build_world.py` → `export_world.py` → `prepare_media.py --manifest-only` → `prepare_repository_assets.py` → `validate_world.py` → `package_release.py --metadata-only`。Python 3.11 / bpy 4.5.3、numpy、scipy、Pillow、ezdxf、shapelyを使用。画像は `render_views.py` で書き出す。

材質別にメッシュを分けてから書き出すため、面ごとの印刷やステージ上面の木材がPC/Quest/FBX/TCM/glTFに引き継がれる。形状検査とCyclesレンダーを実施済み。UnityコンパイルとVRChat内の歩行・ちらつきの最終確認は未実施。
