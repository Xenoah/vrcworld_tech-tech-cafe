# Workにそのまま渡す開始プロンプト

添付した `The_Commons_Compact_Work_Handoff` 一式を読み込み、VRChatワールド **THE COMMONS - Compact Edition** の制作を継続してください。

最初に `00_WORK_HANDOFF_JA.md` と `world_spec.json` を読み、`CAD/The_Commons_Compact_Master.dxf`、個別DXF、`Schedules/`、`Reference/` の順で確認してください。

## ゴール
28m x 18mのコンパクトな2層吹抜け空間を、VRChat向けに実制作できる状態まで詰めること。用途は以下を同一空間で切り替えます。
- 普段のバー / カフェ / 雑談
- 学術発表 / LT / パネルディスカッション
- ポスター / 3Dデモ展示
- DJ / ライブ
- Quietな少人数会話

## 絶対条件
- CAD / `world_spec.json` の寸法を正本とする。
- 参照画像は雰囲気のみ。画像をそのままトレースしない。
- 中央吹抜けと立体的な見下ろし構成を維持する。
- 巨大会場化しない。32人前後で濃い会話が成立する密度を優先する。
- メインの描画方針はフラットライトシェーディング。フォトリアル化しすぎない。
- 暖色のバー/カフェ照明と、青シアンのメディア/DJ照明を役割分担させる。
- 階段にはVR向けの単純化したコライダー、または代替垂直移動を用意する。
- PC版を主、Quest/mobileは軽量フォールバックを用意する。

## 最初に実行してほしいこと
1. DXFからBlender/Unity用の建築グレーボックスを作成。
2. 1F/2F/断面が仕様と一致するか寸法チェック。
3. 1.6m程度の視点高で入口・バー・ステージ・2F見下ろしの視線確認。
4. 3〜6人単位の会話クラスタが自然に形成されるよう家具を仮配置。
5. Academic / Lounge / DJ / Quiet Night のモード状態表を実装仕様へ落とす。
6. その後にマテリアル、照明、AV、ポスター、DJ、外景の順で進める。

不整合がある場合は、黙って解釈せず「CAD正本に対する変更提案」として差分を明示してください。
