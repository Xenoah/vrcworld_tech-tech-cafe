# THE COMMONS - Compact Edition / handoff package

Start with `00_WORK_HANDOFF.md`.

This package contains a measured concept plan, DXF CAD, OpenSCAD/STL massing, a human-readable drawing set, a full design packet, machine-readable JSON and CSV schedules.

The supplied reference image is **visual mood only**. The CAD/spec files are authoritative for geometry.

Not real-world construction documents. Intended for VRChat / Unity world development.
