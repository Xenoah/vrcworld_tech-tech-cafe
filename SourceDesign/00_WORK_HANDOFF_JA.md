# THE COMMONS - Compact Edition | Work引き継ぎ

## 最初に読むもの
Workでは、まずこのファイルと `world_spec.json` を読み、次に `CAD/` と `Schedules/` を参照すること。

**寸法・配置の正本はCAD / JSON。**
`Reference/The_Commons_Compact_reference.png` は雰囲気・密度・立体構成の参考であり、画像内の文字や寸法は正本ではない。

## 一文でいうと
**「学術発表のあと、そのままバーで議論し、上階で深掘りし、夜はDJへ移行できる、小さく濃いVRChatの第三の場所」**。

## 固定条件
- 外形: **28.0 m x 18.0 m**
- 1F: **+0.000 m**
- 2F: **+4.800 m**
- 屋根基準: **+9.600 m**
- 中央は2層吹抜け
- 快適人数: **32人**
- イベント目標: **48人**
- 設計上限目安: **64人**
- 1F: エントランス / バー / カフェ / メインラウンジ / 発表ステージ / ポスター・デモ / AV
- 2F: カフェメザニン / DJブース / Quiet Room / テラス・見下ろし席
- 基本ビジュアル: **暗色ネオインダストリアル + 木と暖色灯 + 控えめな青シアン + フラットライトシェーディング**

## 最重要の設計思想
このワールドは「巨大で凄い会場」ではなく、**人の距離が近く、誰がどこにいるか把握できる空間**にする。

入口から数秒で以下が見えること。
1. バーに人がいるか
2. ステージで何かしているか
3. 2Fに逃げ場があるか
4. Quiet側へ移動できるか

中央吹抜けはただの豪華演出ではなく、1Fと2Fを同じコミュニティとして知覚させるための装置。

## Workでの優先順位
1. CAD寸法どおりにグレーボックス化
2. VR内でアバタースケールと視線を検証
3. 階段、回廊、吹抜け、ステージの導線を検証
4. バー・カフェ・Quiet・ポスターの会話距離を検証
5. Academic / Lounge / DJ / Quiet Night の4モードを実装
6. フラットライト用マテリアルを統一
7. ベイク照明、看板、家具、植栽、外景
8. PC最適化
9. Quest/mobileフォールバック
10. 20〜40人で実地テストして音声距離と家具密度を調整

## Workに変更を許可する範囲
- 家具の細かな形状
- 看板や小物の意匠
- 植栽配置
- 外景
- 壁面の微細な凹凸
- マテリアルの質感

## 勝手に変えない範囲
- 28 x 18 mの基本外形
- 1F / 2Fの高さ関係
- 中央吹抜け
- ステージとメイン画面の軸
- バーが1Fの主たる会話ハブであること
- 2FにQuiet / カフェ / DJを置く立体構成
- 入口から全体の状況が把握できる視線設計

## 成果物の期待値

- Unity/VRChatで歩けるワールド

- 4モード切替
- 発表用大型画面 / タイマー / ポインタ / 3Dデモ台
- ポスター差し替えシステム
- DJ / AudioLink系演出

- ローカル快適設定
- パフォーマンス計測結果
