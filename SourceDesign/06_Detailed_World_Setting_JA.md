# 詳細設定 / ワールドビルディング

## 正式名称
**THE COMMONS - Compact Edition**

愛称候補: **コモンズ / 場 / The Commons**

## 世界観
高密度都市の中層に残った旧「技術交流棟」を、研究者、クリエイター、DJ、エンジニア、学生、趣味人たちが共同で改装した半公共サロン。

元々は都市のデータ中継、技術展示、観測を行う施設だったため、中央には巨大なメディアコアが残っている。現在はそこを発表用スクリーン、ホログラム、イベント演出として再利用している。

ここには「客」と「登壇者」を分ける強い境界がない。壇上で話していた人が10分後にはバーで隣に座っている。その状態を建築そのものが作る。

## 場所ごとの呼称
- **FORUM**: 1F中央ステージ / 発表・パネル・3Dデモ
- **ANCHOR BAR**: 1F西側 / 日常の会話ハブ
- **COMMON TABLES**: 1F南西 / カフェ・軽い会話
- **OPEN LAB**: 1F東側 / ポスター・展示・デモ
- **ORBIT CAFE**: 2F西側 / 観察・作業・少人数会話
- **RELAY**: 2F中央寄り / DJブース
- **ARCHIVE**: 2F東南 / Quiet Room
- **HORIZON**: 2F東北 / 夜景テラス・見下ろし席

## 空間の性格
### 1F
「参加する階」。歩いているだけで、人・発表・バー・展示のどれかに接触する。

### 2F
「残りながら距離を取れる階」。会話を続けてもよいし、下を眺めているだけでもよい。VRにおける社会参加の濃度を自分で調節できる。

## 時間帯演出
### OPEN / 夕方
- 暖色比率高め
- カフェ優先
- ステージは情報ボード
- BGMは低い

### PRIME / 夜
- バーとステージの両方が活性
- 発表、LT、展示に向く
- 青シアンのメディア演出が増える

### LATE / 深夜
- ステージを暗く
- ホログラム回転を低速化
- テラスとQuietの暖色が主役
- 「帰る前の最後の会話」が成立する空気

### DJ EVENT
- RELAYを主役にする
- 中央ラウンジ家具を減らし立ちスペース化
- ただしバー/Quiet/2Fの逃げ場を残す

## サインコピーの方向性
長文を壁一面に置かない。短い言葉だけにする。
- IDEAS TASTE BETTER TOGETHER.
- STAY CURIOUS.
- SAME ROOM. DIFFERENT WORLDS.
- TALK / BUILD / SHARE.
- また、ここで。
- 知を遊ぶ。

## バーの扱い
酒そのものを主役にしない。コーヒー、炭酸、モクテル等も同じ演出格で扱う。
「何を飲むか」より「グラスを持って同じ場所にいる」ことがコミュニケーション装置。

## 学術発表の文化
格式張った講演会ではなく、研究室のゼミと国際学会の懇親会の中間。
- 15分発表
- 5分質疑
- その後すぐバー/ポスターで続きを話せる
という流れが似合う。

## DJ文化
クラブ専用空間ではない。音楽は「会話が終わったら始まるもの」ではなく、「話しながら残れる背景」にもなる。
通常時はDJ設備の存在感を抑え、イベント時だけ建築の焦点を切り替える。

## NPC / AIの扱い
常駐AIバーテンダーを実装する場合、長時間会話を独占させない。
役割は以下に限定する。
- 今日のイベント案内
- 話題カードの提示
- 初参加者への空間案内
- 必要に応じて人と人の会話をつなぐ短い介入

## 禁止したいデザイン
- 入口直後に巨大UI
- 常時点滅するネオン
- 全面鏡張り
- 動画が同時に何枚も動く壁
- 巨大な空席だらけのホール
- 1人では居づらい中央配置のみ
- 迷路のような廊下
- 2Fへ行くと1Fから完全に切り離される構成
- DJ時にQuietまで爆音になる音響
